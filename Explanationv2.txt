## 1. 软件简介

### 1.1 这是什么？
这是一个基于 Python + Tkinter 开发的**图形化内网穿透工具**，无需命令行操作，点点鼠标即可实现：
- 🎮 **游戏联机** - 让朋友通过公网IP连入你的局域网游戏服务器
- 📁 **文件分享** - 一键开启HTTP文件服务器，支持上传下载、二维码分享
- 🖥️ **远程桌面** - 穿透 RDP(3389) / VNC(5900) 端口，随时远程控制家里电脑
- 🔧 **端口映射** - 自定义 TCP/UDP 端口转发，适配各种服务
- 🛠️ **网络工具箱** - 内置端口扫描、延迟测试、公网IP查询等实用工具

### 1.2 支持的穿透方式

| 方式 | 适用场景 | 需要公网服务器 | 稳定性 | 配置难度 |
|------|----------|----------------|--------|----------|
| **FRP客户端模式** | 长期稳定运行、多端口映射 | ✅ 是 | ⭐⭐⭐⭐⭐ | 中等 |
| **简单TCP穿透** | 临时测试、单端口转发 | ❌ 否 | ⭐⭐⭐ | 简单 |
| **文件服务器** | 局域网/公网文件分享 | ❌ 否 | ⭐⭐⭐⭐ | 简单 |

## 2. 环境要求与安装

### 2.1 系统要求
- **Windows 10/11** (主要测试平台)
- **Python 3.8+** (推荐 3.10/3.11)
- 内存 50MB+，磁盘 20MB+

### 2.2 安装步骤

#### 方式一：直接运行源码（开发者/调试）
```bash
# 1. 克隆/下载项目到任意目录
cd D:\your_path\NetworkTunnel

# 2. 安装依赖
pip install -r requirements.txt
# 或者手动安装核心依赖：
pip install cryptography requests pillow qrcode psutil

# 3. 运行
python main.py
```

#### 方式二：使用打包好的 EXE（普通用户）
1. 双击 `dist/NetworkTunnel.exe` 直接运行
2. 首次运行会自动创建配置文件
3. **重要**：如果使用 FRP 功能，请将 `frpc.exe` 放在程序同目录下

#### 方式三：一键安装脚本（Windows）
```cmd
# 以管理员身份运行 cmd，执行：
install.bat
```
这会自动安装依赖、创建桌面快捷方式、检查 frpc。

### 2.3 FRP 客户端准备（仅 FRP 模式需要）
1. 访问 https://github.com/fatedier/frp/releases
2. 下载对应系统的压缩包（Windows 选 `windows_amd64.zip`）
3. 解压后将 **`frpc.exe`** 复制到本工具目录下
4. 服务端配置参考：`docs/frps.ini.example`

## 3. 核心功能模块详解

### 3.1 标签页一：FRP 穿透 🌐
> **适合**：有公网服务器、需要长期稳定、多端口同时映射

#### 界面布局
```
┌─ 服务器配置 ────────────────────────────────────┐
│ 服务器地址: [frp.example.com      ]  端口: [7000] │
│ Token:      [********************]              │
└─────────────────────────────────────────────────┘
┌─ 端口映射列表 ──────────────────────────────────┐
│ 名称      │ 类型 │ 本地端口 │ 远程端口 │ 操作   │
│ Minecraft │ TCP  │ 25565    │ 25565    │ 编辑/删│
│ Web服务   │ TCP  │ 8080     │ 8080     │ 编辑/删│
└─────────────────────────────────────────────────┘
        [添加映射] [删除映射] [编辑映射]
        [▶ 启动FRP] [⏹ 停止FRP]
┌─ 连接状态日志 ──────────────────────────────────┐
│ 2024-01-15 10:30:12 [INFO] FRP客户端已启动       │
│ 2024-01-15 10:30:15 [INFO] 代理 Minecraft 已连接 │
└─────────────────────────────────────────────────┘
```

#### 详细配置步骤

**步骤 1：准备 FRP 服务端**
在你的公网服务器上创建 `frps.ini`：
```ini
[common]
bind_port = 7000                    # 客户端连接端口
vhost_http_port = 80                # HTTP穿透端口(可选)
vhost_https_port = 443              # HTTPS穿透端口(可选)
token = your_strong_password_here   # 认证令牌(必须与客户端一致)
dashboard_port = 7500               # 管理面板端口(可选)
dashboard_user = admin
dashboard_pwd = admin123
```

启动服务端：
```bash
# Linux/Mac
./frps -c frps.ini

# Windows
frps.exe -c frps.ini

# 后台运行建议使用 systemd/supervisor/nssm
```

**步骤 2：客户端配置**
| 字段 | 说明 | 示例 |
|------|------|------|
| 服务器地址 | 你的公网服务器IP或域名 | `frp.example.com` 或 `1.2.3.4` |
| 服务器端口 | frps 的 bind_port | `7000` |
| Token | 与服务端一致的认证密钥 | `your_strong_password_here` |

**步骤 3：添加端口映射**
点击「添加映射」按钮，填写：
| 字段 | 说明 | 示例 |
|------|------|------|
| 映射名称 | 唯一标识，不能重复 | `Minecraft` `Web服务` `SSH` |
| 协议类型 | TCP 或 UDP | `TCP` (大多数情况) |
| 本地端口 | 你电脑上服务的端口 | `25565` `8080` `22` |
| 远程端口 | 服务端暴露的端口 | `25565` `8080` `2222` |

> ⚠️ **注意**：远程端口在服务端必须未被占用。多个映射的远程端口不能冲突。

**步骤 4：启动**
点击「▶ 启动FRP」，观察下方日志：
```
[INFO] FRP客户端已启动
[INFO] 正在连接服务器 frp.example.com:7000...
[INFO] 登录成功
[INFO] 代理 Minecraft 已启动
[INFO] 代理 Web服务 已启动
```

**步骤 5：朋友连接**
告诉朋友连接地址：**`你的公网IP:远程端口`**
- Minecraft: `frp.example.com:25565`
- Web服务: `http://frp.example.com:8080`

### 3.2 标签页二：简单穿透 ⚡
> **适合**：临时测试、无公网服务器、单端口快速转发

#### 原理说明
这是一个**本地 TCP 端口转发器**：
```
外部连接 → [你的公网IP:监听端口] → 本工具 → [127.0.0.1:目标端口] → 你的本地服务
```

#### 配置字段
| 字段 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| 监听端口 | 本工具监听的端口，需在路由器做端口映射 | `8080` | `8080` `25565` |
| 目标地址 | 要转发到的本地服务地址 | `127.0.0.1` | `127.0.0.1` `192.168.1.100` |
| 目标端口 | 本地服务的实际端口 | `80` | `80` `25565` `3389` |
| 协议类型 | 传输协议 | `TCP` | `TCP` `UDP` |
| 启用加密 | 使用 Fernet 对称加密传输数据 | `关闭` | `开启`(实验性) |

#### 使用前提 ⚠️
**必须在路由器设置「端口转发/虚拟服务器」**：
```
路由器管理界面 → 端口转发 → 添加规则:
- 外部端口: 8080 (或你设置的监听端口)
- 内部IP: 你电脑的局域网IP (如 192.168.1.5)
- 内部端口: 8080
- 协议: TCP
```

#### 适用场景对比
| 场景 | 推荐方式 |
|------|----------|
| 家里有公网IP + 路由器可配置 | ✅ 简单穿透 |
| 公司/学校网络、无路由器权限 | ❌ 请用 FRP 或 ZeroTier |
| 临时演示、测试几分钟 | ✅ 简单穿透 |
| 长期运行、需要稳定 | ❌ 请用 FRP |

### 3.3 标签页三：文件分享 📁
> **适合**：向朋友发送大文件、手机电脑互传、临时文件服务器

#### 功能特性
- ✅ 现代化 Web 界面，手机电脑均可访问
- ✅ 支持**拖拽上传**、**多文件上传**
- ✅ 支持**文件夹浏览**、**文件下载**
- ✅ 可选**访问密码**（Basic Auth）
- ✅ 可选**只读模式**（禁止上传）
- ✅ **二维码分享**链接
- ✅ 实时访问日志

#### 配置字段
| 字段 | 说明 | 示例 |
|------|------|------|
| 分享目录 | 要对外暴露的文件夹路径 | `D:\Share` `C:\Users\Public` |
| 服务端口 | HTTP 服务端口 | `8000` `8080` |
| 访问密码 | 留空则无需密码 | `123456` |
| 只读模式 | 勾选后禁止上传/删除 | `开启` |

#### 使用步骤
1. 点击「浏览」选择要分享的文件夹
2. 设置端口（默认 8000）
3. 可选：设置密码、开启只读模式
4. 点击「▶ 启动服务」
5. 点击「🌐 打开浏览器」或复制日志中的地址发给朋友

#### 访问地址格式
```
局域网:  http://192.168.1.xxx:8000
公网:    http://你的公网IP:8000 (需路由器端口映射或 FRP 穿透)
```

#### 结合 FRP 实现公网文件分享
在 FRP 映射中添加：
- 名称: `文件分享`
- 类型: `TCP`
- 本地端口: `8000`
- 远程端口: `8000`

朋友访问: `http://frp.example.com:8000`

### 3.5 标签页五：远程桌面 🖥️
> **适合**：远程控制家里/公司电脑

#### VNC 穿透
- **默认端口**: 5900 (VNC Server 默认)
- **配置**: VNC Server 设置密码、允许本地连接
- **客户端连接**: `你的公网IP:外网端口` (VNC Viewer 中输入)

#### RDP 穿透 (Windows 远程桌面)
- **默认端口**: 3389
- **前置条件**:
  1. 目标电脑: 设置 → 系统 → 远程桌面 → 启用
  2. 防火墙允许 3389 端口
  3. 用户账户有密码 (空密码无法 RDP)
- **客户端连接**: `mstsc` → 计算机: `你的公网IP:外网端口`

#### 安全建议 ⚠️
| 建议 | 说明 |
|------|------|
| 强密码 | 必须设置复杂密码，RDP 爆破很常见 |
| 修改端口 | 可将外网端口改为非常用端口 (如 33890) |
| 仅 FRP | 建议仅通过 FRP 穿透，不直接在路由器映射 3389 |
| 证书 | 企业环境建议配置 RDP 证书 |

## 4. 使用场景实例

### 场景一：和朋友联机 Minecraft (最常见) 🎮

**你的环境**：家里宽带，无公网IP，有路由器管理权限
**朋友环境**：任意网络

**方案 A：使用 FRP (推荐，最稳定)**
```
准备:
1. 买一台云服务器 (1核1G足够，约 ¥30-50/月)
2. 服务器部署 frps (见 3.1 步骤1)
3. 本工具配置 FRP 客户端 (见 3.1 步骤2-3)

映射添加:
- 名称: MC_Java, 类型: TCP, 本地: 25565, 远程: 25565

朋友连接:
- 地址: 你的服务器IP:25565
```

**方案 B：路由器端口映射 + 简单穿透 (免费，需公网IP)**
```
前提: 你的宽带有公网IP (打电话运营商要，或桥接光猫拨号)

路由器设置:
- 端口转发: 外部 25565 → 内部 192.168.1.xxx:25565

本工具简单穿透:
- 监听端口: 25565
- 目标地址: 127.0.0.1
- 目标端口: 25565

朋友连接:
- 地址: 你的公网IP:25565
```

**方案 C：ZeroTier / Tailscale (最简单，无需服务器)**
```
1. 你和朋友都安装 ZeroTier
2. 加入同一个 Network ID
3. 直接用 ZeroTier 虚拟IP 连接 (如 10.147.x.x:25565)
4. 无需任何端口映射、穿透配置
```

## 5. 常见问题解决 (FAQ) ❓

### 5.1 启动/运行问题

**Q: 双击 main.py 没反应 / 报错 `ModuleNotFoundError`**
```
A: 缺少依赖库。运行:
   pip install -r requirements.txt
   或:
   pip install cryptography requests pillow qrcode psutil
```

**Q: 报错 `_tkinter.TclError: cannot use geometry manager grid...`**
```
A: 这是布局管理器冲突。已在最新版修复，请更新代码。
   或手动修改 create_settings_page，将 grid 改为 pack。
```

**Q: 启动 FRP 显示 "找不到 frpc.exe"**
```
A: 请下载 FRP 客户端:
   1. https://github.com/fatedier/frp/releases
   2. 下载 frp_x.x.x_windows_amd64.zip
   3. 解压，将 frpc.exe 复制到本程序同目录
```

**Q: 程序闪退 / 无界面**
```
A: 尝试在命令行运行查看报错:
   python main.py
   常见原因: 缺少模块、配置文件损坏、端口被占用
```

---

### 5.2 连接/穿透问题

**Q: FRP 启动成功但朋友连不上**
```
排查清单:
□ 服务端 frps 是否运行? (systemctl status frps / 看进程)
□ 服务器防火墙/安全组是否放行 7000 和 远程端口?
□ 客户端日志是否显示 "代理 xxx 已启动"?
□ 远程端口在服务端是否被其他程序占用? (netstat -ntlp)
□ 朋友连接的 IP/端口是否正确?
□ 本地服务是否真的在监听本地端口? (netstat -an | findstr 25565)
```

**Q: 简单穿透连不上 / 超时**
```
排查清单:
□ 路由器端口映射是否正确配置? (外部端口=监听端口, 内部IP=你电脑局域网IP)
□ 电脑防火墙是否放行监听端口? (入站规则/关闭防火墙测试)
□ 本地服务是否启动且监听正确端口?
□ 你的宽带是否有公网IP? (搜 "ip" 对比路由器WAN口IP)
□ 运营商是否封禁常用端口? (尝试改大号端口如 25565→25566)
```

**Q: 文件分享手机访问不了**
```
排查:
□ 手机和电脑是否同一 WiFi? (局域网互访前提)
□ 电脑防火墙是否放行 8000 端口?
□ 地址栏输入的是否为 http://电脑局域网IP:8000 (不是 127.0.0.1)
□ 尝试电脑浏览器先访问同一地址测试
```

**Q: Minecraft 基岩版/饥荒等 UDP 游戏连不上**
```
说明: 简单穿透的 UDP 支持有限，FRP 需额外配置

方案:
1. FRP 服务端 frps.ini 添加:
   bind_udp_port = 7000  # 或其他端口
   
2. 客户端映射类型选 UDP

3. 或使用 ZeroTier/Tailscale (原生支持 UDP，最省心)
```

---

### 5.3 性能/速度问题

**Q: 传输速度很慢 (只有几百 KB/s)**
```
可能原因:
1. 服务器带宽限制 (云服务器通常 1-5 Mbps)
2. FRP 单线程转发瓶颈
3. 网络丢包/延迟高
4. 加密开启导致 CPU 占用高

优化:
□ 关闭简单穿透的"启用加密"选项
□ 服务端调大 proxy_bind_addr = 0.0.0.0
□ 使用 KCP 协议 (frpc.ini: protocol = kcp)
□ 升级服务器带宽
□ 就近选择服务器地区
```

**Q: 延迟很高 / 丢包严重**
```
测试方法:
工具菜单 → 测试延迟 → 输入服务器IP → 端口 7000 → 测试 20 次

判断:
- 平均延迟 < 50ms: 优秀
- 50-100ms: 良好，游戏可玩
- 100-200ms: 一般，有延迟感
- > 200ms: 差，建议换服务器

优化:
□ 选离你物理位置近的服务器
□ 尝试不同线路 (电信/联通/移动/BGP)
□ 启用 FRP 的 KCP/QUIC 协议
```

### 5.4 配置/数据问题

**Q: 配置不生效 / 重启后丢失**
```
配置文件位置: 程序目录下 config.json
- 手动修改后需重启程序
- "保存设置" 按钮会写入此文件
- 权限问题: 以管理员运行或移到非系统盘目录
```

**Q: 怎么备份/迁移配置？**
```
备份文件:
- config.json (所有设置)
- tunnel.log (运行日志)

迁移: 复制这两个文件到新电脑同目录即可
```

**Q: 日志文件太大怎么办？**
```
设置 → 日志保留天数 → 改为 3 或 1
或手动删除 tunnel.log
程序启动时会自动清理过期日志
```

## 6. 进阶配置 🔧

### 6.1 FRP 进阶配置 (frpc.ini 手动编辑)

程序生成的配置在 `frpc.ini`，可手动修改后重启生效：

```ini
[common]
server_addr = frp.example.com
server_port = 7000
token = your_token
# 进阶选项:
protocol = tcp              # 可选: tcp, kcp, quic, websocket
tls_enable = true           # 启用 TLS 加密传输
pool_count = 5              # 连接池大小，加快建连
tcp_mux = true              # 多路复用
heartbeat_interval = 10     # 心跳间隔
heartbeat_timeout = 90      # 心跳超时

[Minecraft]
type = tcp
local_ip = 127.0.0.1
local_port = 25565
remote_port = 25565
# 进阶:
use_encryption = true       # 加密传输
use_compression = true      # 压缩传输
```

### 6.2 系统服务化 (开机自启、后台运行)

#### Windows (使用 NSSM)
```cmd
# 下载 nssm.exe
nssm install NetworkTunnel
# Path: D:\NetworkTunnel\NetworkTunnel.exe
# Startup directory: D:\NetworkTunnel
# Arguments: (留空)
nssm start NetworkTunnel
```

#### Linux (systemd)
```ini
# /etc/systemd/system/network-tunnel.service
[Unit]
Description=Network Tunnel Tool
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/home/youruser/NetworkTunnel
ExecStart=/usr/bin/python3 main.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable network-tunnel
systemctl start network-tunnel
```

