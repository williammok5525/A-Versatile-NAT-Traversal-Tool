                        一、程序简介
═══════════════════════════════════════════════════════════════════

【程序概述】
本工具是一款集成了多种内网穿透方式的GUI应用程序，旨在帮助用户
轻松实现内网穿透、文件共享、游戏联机等功能。

【主要功能】
• FRP穿透      - 基于FRP的稳定穿透方案（需服务器）
• 简单穿透      - 无需服务器的快速穿透
• 文件分享      - 一键开启HTTP文件服务器
• 游戏联机      - 预设主流游戏端口配置
• 远程桌面      - VNC/RDP远程控制穿透
• 工具集        - IP查询、端口扫描、延迟测试等

【系统要求】
• Windows 7/8/10/11 或 Linux/Mac
• Python 3.8 或更高版本
• 网络连接（用于获取公网IP等功能）

═══════════════════════════════════════════════════════════════════
                      二、FRP穿透功能
═══════════════════════════════════════════════════════════════════

【功能说明】
FRP（Fast Reverse Proxy）是一种高性能的反向代理应用，可以将
内网服务通过具有公网IP的服务器暴露到公网。

【使用前提】
1. 必须有一台拥有公网IP的服务器（VPS/云服务器）
2. 服务器上已安装并运行FRP服务端（frps）
3. 本地电脑安装FRP客户端（frpc.exe）

【详细步骤】

步骤1：服务器端配置（只需配置一次）
────────────────────────────────────
在你的公网服务器上：

1. 下载FRP：https://github.com/fatedier/frp/releases
2. 解压后编辑 frps.ini：
   
   [common]
   bind_port = 7000
   token = your_secret_token_here

3. 启动服务端：
   Linux/Mac:  ./frps -c frps.ini
   Windows:    frps.exe -c frps.ini

4. 确保防火墙开放7000端口

步骤2：客户端配置（本工具）
─────────────────────────
1. 打开本工具，切换到 "FRP穿透" 标签页

2. 填写服务器配置：
   • 服务器地址：你的公网服务器IP（如：1.2.3.4）
   • 服务器端口：7000（与服务端bind_port一致）
   • Token：your_secret_token_here（与服务端token一致）

3. 添加端口映射：
   点击 "添加映射" 按钮，填写：
   • 映射名称：game（自定义名称）
   • 协议类型：TCP（通常选TCP）
   • 本地端口：25565（你要穿透的服务端口）
   • 远程端口：25565（外网访问的端口）

4. 点击 "启动FRP" 按钮

步骤3：验证连接
───────────────
1. 查看 "连接状态" 窗口，确认显示连接成功
2. 访问 http://你的服务器IP:远程端口 测试

【示例场景】
假设你想让朋友连接你本地的Minecraft服务器：

本地Minecraft端口：25565
服务器IP：203.0.113.50
配置映射：
  名称：minecraft
  类型：TCP
  本地：25565
  远程：25565

朋友连接地址：203.0.113.50:25565

【注意事项】
⚠️ 远程端口不能与服务器已有服务冲突
⚠️ Token必须与服务端完全一致
⚠️ 确保服务器防火墙已开放相应端口

═══════════════════════════════════════════════════════════════════
                      三、简单穿透功能
═══════════════════════════════════════════════════════════════════

【功能说明】
简单穿透是无需服务器的点对点穿透方案，适合临时使用或小规模
数据转发。

【适用场景】
• 临时文件传输
• 快速测试服务
• 不想配置服务器的情况

【详细步骤】

1. 切换到 "简单穿透" 标签页

2. 配置参数：
   • 监听端口：本机监听的端口（如8080）
     → 这是外网访问的入口端口
   
   • 目标地址：通常填 127.0.0.1
     → 表示转发到本机服务
   
   • 目标端口：你要转发到的本地服务端口
     → 例如你的Web服务器在80端口，就填80
   
   • 协议类型：TCP 或 UDP
     → 大多数服务用TCP，游戏可能用UDP
   
   • 启用加密传输：可选
     → 勾选后数据会加密（需要对方也支持）

3. 点击 "启动穿透"

4. 状态会显示 "穿透运行中"

【工作原理】
外部请求 → 你的公网IP:监听端口 → 本工具转发 → 本地服务

【示例】
你本地运行了一个Web服务器在8080端口：

监听端口：9000
目标地址：127.0.0.1
目标端口：8080

朋友访问：你的公网IP:9000 即可访问你的Web服务

【注意事项】
⚠️ 需先在路由器设置端口转发
⚠️ 确保防火墙允许该端口入站
⚠️ 公网IP需固定或使用动态域名

                      四、文件分享功能
═══════════════════════════════════════════════════════════════════

【功能说明】
快速将本地文件夹通过HTTP协议分享出去，支持文件浏览、下载，
可选上传功能。

【详细步骤】

1. 切换到 "文件分享" 标签页

2. 配置分享参数：
   • 分享目录：点击"浏览"选择要分享的文件夹
     示例：D:\Share\Files
   
   • 服务端口：默认8000，可修改
     示例：9000
   
   • 访问密码：可选，设置后需输入密码才能访问
     示例：mypassword123
   
   • 只读模式：勾选后禁止上传文件（推荐）

3. 点击 "启动文件服务"

4. 查看访问地址：
   日志会显示：访问地址: http://192.168.1.100:9000

5. 分享给朋友：
   • 局域网内：直接访问上述地址
   • 外网访问：需配合穿透功能

【Web界面功能】
• 📁 文件夹：点击进入子目录
• 📄 文件：点击直接下载
• 📤 上传：（非只读模式）支持拖拽上传
• 图标：根据文件类型自动显示

【访问控制】
• 无密码：任何人可访问
• 有密码：弹出认证对话框，输入密码后访问
• 只读模式：只能浏览和下载，不能上传

【示例场景】
分享游戏存档给朋友：

1. 选择存档文件夹：C:\Games\Saves
2. 端口：8080
3. 密码：game2024
4. 启动服务
5. 告诉朋友：http://你的IP:8080

【注意事项】
⚠️ 分享敏感文件务必设置密码
⚠️ 大文件传输可能占用较多带宽
⚠️ 建议启用只读模式防止误操作

                      五、游戏联机功能
═══════════════════════════════════════════════════════════════════

【功能说明】
预设了主流游戏的端口配置，一键开启游戏服务器穿透。

【支持的游戏】
• Minecraft Java版    - 端口 25565
• Minecraft 基岩版    - 端口 19132
• Terraria            - 端口 7777
• 饥荒 (Don't Starve) - 端口 10999
• ARK: Survival       - 端口 7777
• CS:GO               - 端口 27015
• 自定义游戏          - 手动填写端口

【详细步骤】

1. 切换到 "游戏联机" 标签页

2. 选择游戏类型：
   下拉菜单选择你的游戏，端口会自动填充

3. 确认端口配置：
   • 游戏端口：本地游戏服务器端口（自动填充）
   • 外网端口：外网访问端口（通常与游戏端口相同）

4. 点击 "启动联机"

5. 获取连接地址：
   点击 "复制连接地址"
   格式：公网IP:外网端口

6. 分享给朋友

【示例：Minecraft联机】

场景：你在家开服，朋友在外网连接

1. 启动Minecraft服务器（监听25565端口）
2. 工具中选择 "Minecraft Java版"
3. 端口自动填充：25565
4. 点击启动联机
5. 复制地址：203.0.113.50:25565
6. 发给朋友

朋友在游戏中：
• 单人游戏 → 多人游戏 → 直接连接
• 输入：203.0.113.50:25565

【进阶配置】
如果游戏端口与外网端口不同：

游戏端口：25565（本地）
外网端口：25566（外网访问）

朋友连接：你的IP:25566

【注意事项】
⚠️ 确保游戏服务器已启动
⚠️ 防火墙需放行游戏端口
⚠️ 某些游戏需要UDP协议支持

═══════════════════════════════════════════════════════════════════
                      六、远程桌面功能
═══════════════════════════════════════════════════════════════════

【功能说明】
将本地的VNC或RDP远程桌面服务穿透到公网，实现远程控制。

【VNC vs RDP】
• VNC：跨平台，适合Linux/Mac/Windows
• RDP：Windows原生，性能更好

【详细步骤】

【VNC配置】
1. 本地安装VNC服务器（如TightVNC、RealVNC）
2. VNC默认端口：5900
3. 工具中切换到 "远程桌面"
4. 填写VNC端口：5900
5. 外网端口：5900（或自定义）
6. 点击 "启动VNC穿透"
7. 连接地址会显示在信息框中

【RDP配置】
1. Windows系统默认开启RDP（需专业版）
2. RDP默认端口：3389
3. 工具中填写RDP端口：3389
4. 点击 "启动RDP穿透"

【连接方式】

VNC客户端连接：
• 下载VNC Viewer
• 输入：你的公网IP:外网端口
• 输入VNC密码

Windows远程桌面连接：
• Win+R → 输入 mstsc
• 输入：你的公网IP:外网端口
• 输入Windows账号密码

【安全建议】
🔒 务必设置强密码
🔒 限制可连接的IP段
🔒 考虑使用VPN替代直接暴露

【注意事项】
⚠️ RDP仅Windows专业版支持
⚠️ 确保远程桌面功能已开启
⚠️ 注意网络安全风险

                      八、设置说明
═══════════════════════════════════════════════════════════════════

【通用设置】
───────────
• 开机自启动
  勾选后程序随系统启动（需管理员权限）

• 最小化到托盘
  关闭窗口时最小化到系统托盘而非退出

• 断线自动重连
  网络断开后自动尝试重新连接

【网络设置】
───────────
• 连接超时(秒)
  默认30秒，连接等待时间

• 缓冲区大小(KB)
  默认4096KB，数据传输缓冲区

【日志设置】
───────────
• 保存日志到文件
  将日志保存到 tunnel.log 文件

• 日志保留天数
  自动清理超过天数的旧日志

【配置保存】
配置文件保存在：config.json
包含所有设置和最近使用的服务器

【恢复默认】
点击"恢复默认"按钮可重置所有设置

                      九、常见问题
═══════════════════════════════════════════════════════════════════

Q1: 启动FRP失败，提示找不到frpc.exe？
A: 下载FRP客户端 https://github.com/fatedier/frp/releases
   将frpc.exe放在程序同一目录下

Q2: 朋友无法连接我的服务？
A: 检查：
   1. 防火墙是否放行端口
   2. 路由器端口转发是否配置
   3. 服务是否正常运行
   4. 公网IP是否正确

Q3: 如何获取公网IP？
A: 工具会自动获取，如失败可访问：
   https://ip.sb 或 https://ipip.net

Q4: 端口被占用怎么办？
A: 使用端口扫描器查看，或更换其他端口

Q5: FRP连接不上服务器？
A: 检查：
   1. 服务器FRP服务端是否运行
   2. Token是否一致
   3. 服务器防火墙是否开放端口
   4. 网络是否通畅（ping测试）

Q6: 文件分享无法访问？
A: 检查：
   1. 目录路径是否正确
   2. 端口是否被占用
   3. 浏览器是否输入正确地址

Q7: 游戏延迟很高？
A: 尝试：
   1. 选择更近的服务器节点
   2. 关闭不必要的程序
   3. 使用有线网络而非WiFi

Q8: 如何卸载程序？
A: 直接删除程序文件夹即可，无需卸载

                      十、进阶技巧
═══════════════════════════════════════════════════════════════════

【技巧1：结合使用】
FRP + 文件分享 = 外网访问本地文件
1. 用FRP映射8000端口
2. 启动文件分享在8000端口
3. 朋友通过公网IP访问

【技巧2：多端口映射】
一个FRP可同时映射多个服务：
• 25565 → Minecraft
• 8080  → Web服务
• 22    → SSH

【技巧3：动态域名】
如果公网IP经常变化：
1. 申请动态域名（如：no-ip.com）
2. 配置DDNS客户端
3. 使用域名替代IP

【技巧4：安全加固】
• 使用强密码/Token
• 限制连接IP段
• 定期更换端口
• 启用加密传输

【技巧5：性能优化】
• 增大缓冲区大小
• 关闭不必要的日志
• 使用有线网络
• 选择低延迟服务器
