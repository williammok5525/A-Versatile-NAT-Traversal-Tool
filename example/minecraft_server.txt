# Minecraft服务器穿透示例

## 场景
你想和朋友联机玩Minecraft，但你没有公网IP

## 解决方案

### 方法1: 使用FRP (推荐)

1. 准备工作:
   - 一台有公网IP的服务器 (例如: 1.2.3.4)
   - 在服务器上运行FRP服务端

2. 在工具中配置:
   - 服务器地址: 1.2.3.4
   - 服务器端口: 7000
   - 添加映射: Minecraft (TCP) 25565 -> 25565

3. 启动穿透

4. 告诉朋友连接: 1.2.3.4:25565

### 方法2: 使用简单穿透

1. 确保你的路由器支持端口转发
2. 在路由器中转发25565端口到你的电脑
3. 在工具中:
   - 监听端口: 25565
   - 目标: 127.0.0.1:25565
4. 告诉朋友你的公网IP
